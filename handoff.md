## 7. Як запустити
GitHub → Actions → `video` → Run workflow:
- dry run готового сценарію: `story` = id, `upload` = no → відео в гілці `preview`, лог у `logs`;
- бот пише сам: `write` = true, `story` порожнє;
- приватне завантаження без часу: `upload` = private;
- у найближчий вільний слот: `upload` = slot; у точну хвилину: ще `publish_at` (UTC) і `slot` (ключ `E<дата>#N`);
- виставити час уже завантаженому: `schedule_video` = id відео + `publish_at` + `slot` + `story`;
- пошук тем: `scout` = 20; перевірка каналу: `youtube_check` = true.

Вимкнути розклад: у `data/config.json` поставити `"live": false` і закомітити в `main`. Вмикати, вимикати й
міняти слоти — тільки за словом Андрія.
