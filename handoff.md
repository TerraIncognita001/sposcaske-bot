# handoff.md — sposcaske-bot

Стан на 14 листопада 2026, версія **v1.04**. Власник — Андрій (пише українською, хоче короткі відповіді по суті).
Перед роботою прочитай `CLAUDE.md` (жорсткі правила, система версій) — цей файл їх не замінює.

## 1. Ціль
Автономний бот, який сам знаходить тему, пише сценарій, шукає матеріали, знімає й публікує YouTube Shorts у жанрі
каналу-референсу (TikTok @doom.lore): темна історія мистецтва — одна стара картина, низький спокійний голос, одна
деталь, після якої картина вже не виглядає невинною. Усе безкоштовними інструментами, на GitHub Actions.
Канал: **sposcaske** (@sposcaske, id UCNamDfqgZhL8JOaAiCNY_ww). Розклад: щодня **15:00 і 02:00 за Лондоном**.

## 2. Теперішній стан
Весь ланцюжок збудований і перевірений по частинах:

| ланка | стан |
|---|---|
| пошук і оцінка тем 1–10 (`topics.py`) | працює наживо; у `data/backlog.json` 11 тем із балом 7+ |
| сценарист (`writer.py`, Gemini) | працює наживо, написав 1 сценарій сам; за кутом судді ще НЕ писав |
| режисер (`director.py`) | працює: сам розставляє камеру, червоне слово, картку, портрет |
| матеріали (`sources.py`) | працює: Commons, Wikidata, перевірка ліцензій, обрізка портрета по обличчю |
| рендер (`render.py`) | затверджений макет (демо 7) + кілька зображень в одному відео |
| перевірка відповідності макету (`bot.py`) | 12 перевірок, відео з провалом не завантажується |
| завантаження (`upload.py`) | працює: тестове відео на каналі приватним — https://youtube.com/shorts/vquovec65EM |
| розклад (`gate.py`, cron) | збудований, **ВИМКНЕНИЙ**: `data/config.json` → `"live": false` |

**Що чекає на Андрія:**
1. Подивитися тестове відео в YouTube Studio і сказати, чи вмикати розклад (`"live": true`). Без його «так» не вмикати.
2. Підтвердити канал телефоном (youtube.com/verify) — зараз статус `eligible`, тобто не підтверджено.
3. Обрати аватарку з `assets/brand/` (шість варіантів) і сказати назву каналу для банера.

**Що ще не збудовано:** обкладинки, статистика і самонавчання (`stats_now.py`, `learn.py`), перевірка зображень на
оголеність, нічна рутина Claude-сценариста (є тільки Gemini), 10-денна гілка `draft` (вмикається, коли підуть відео).

## 5. Що пробували
- Копіювати референс «у дусі» → Андрій відхилив. Тільки покадровий і позвуковий розбір дав прийнятний макет.
- Синтезувати стартовий звук за спектром → замінено на файл Андрія.
- Мерехтіння: спершу за вимірами (0,8 %) — непомітне; потім кольорові плями — «занадто сильне й кольорове»;
  затверджено теплу «свічку зліва», потім посилено (`overlays.candle.amp` 0.08).
- Шрифт червоного слова: Grenze з хвилястим краєм («як рифлена картопля фрі») → Bevan → **Gloock** (вибір Андрія).
- Окремий шаблон «легенда» під відео про Тартіні (темна сепія, без червоного слова) — запропоновано, але Андрій
  вирішив інакше: **один макет для всіх тем**, легенди йдуть у ті самі 13 слотів (форма S2 «In 1713, a violinist
  named …»).
- Тема «Занепалий ангел» з кутом «руки» (вибір бота) → Андрій: «зовсім не цікава». Та сама картина — №2 на
  каналі-референсі з кутом «сльоза й погляд». Висновок: тема = картина + кут; кут тепер обирає суддя.

## 6. Що не спрацювало
- **Wikimedia з хмарної пісочниці Claude** — постійно 429. З раннерів GitHub працює. Тому пошук і завантаження
  зображень перевіряються тільки через запуск у Actions (`pictures_only`, `_selftest`).
- **Квота Gemini.** Один пошук тем (~40 запитів із картинкою) з'їв денний безкоштовний ліміт сильних моделей;
  сценарист після нього не зміг працювати (слабша модель не дала придатної розмітки картини). Пошук тем — раз на
  тиждень (неділя 05:05 UTC), окремо від відео. `gemini-2.5-flash` повертає 404 (закрита для нових користувачів).
- **Суддя завищив «Нічний кошмар»** (9), хоча на каналі-референсі це відео серед найслабших: не зняв бали за
  чудовисько в повний зріст. Такі дев'ятки читати як сімки, доки немає власної статистики.
- **Перший сценарій бота**: хук одразу розкрив деталь, джерело розмите («According to historical records»).
  Заборонено в промпті, але на новому сценарії ще не перевірено.
- **Сильне наближення** (5×) на малу деталь розмивало картинку → обмежено до 3,6×.
- **Пік гучності**: клацання затвора разом зі стартом голосу давало +0,2 дБ після AAC → клацання тихіше на 3 дБ
  і запобіжник у `render.py`.
- **Зведення стартового звуку в моно** з'їдало його ширину → вихід тепер стерео.
- **Edge TTS** відповідає 403; **Azure** потребує ключа й картки → лишився офлайн Kokoro.
- **Створення репозиторію та читання списку секретів із сесії** — заборонено проксі; репозиторій створював Андрій.
- **Власний слух відсутній**: звук і голос я перевіряю тільки вимірами (кореляція, LUFS, F0). Остаточну оцінку
  на слух дає Андрій.

## 7. Як запустити
GitHub → Actions → `video` → Run workflow:
- dry run готового сценарію: `story` = id, `upload` = no → відео в гілці `preview`, лог у `logs`;
- бот пише сам: `write` = true, `story` порожнє;
- приватне тестове завантаження: `upload` = private;
- пошук тем: `scout` = 20;
- перевірка каналу: `youtube_check` = true.

Увімкнути розклад (тільки після «так» від Андрія): у `data/config.json` поставити `"live": true`, закомітити в `main`.
